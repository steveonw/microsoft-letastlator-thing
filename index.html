PolicyTrace — build 27

The current PolicyTrace contest application is a local client/server app. The product frontend lives in frontend/app/ and is served by backend/run_app.py.

Run the current product

python -m pip install -r backend/requirements.txt
python backend/run_app.py

Then open http://127.0.0.1:8777/.
